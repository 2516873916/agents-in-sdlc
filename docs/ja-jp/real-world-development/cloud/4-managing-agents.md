ここ数回の演習で、Copilot cloud agent にユーザー体験の改善と機能追加を目的とする 3 つのタスクを依頼しました。cloud agent は非同期かつ自律的に動作しますが、タスクを監視することも重要です。

GitHub.com の[エージェントページ][agents-page]など、cloud agent に割り当てたタスクを管理するツールがいくつかあります。この mission control では、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行された操作を調べたり、進行中のセッションに追加の指示を与えたりできます。

このレッスンでは、次のことを行います。

- エージェントページで cloud agent のタスクを監視します。
- 進行中のセッションに追加の機能を依頼して、作業を導きます。

## シナリオ

ハイコントラストモードの作成をエージェントに割り当てた後、チームはライトモードも追加するとよいと考えました。サイトのスタイルと切り替え機能をすでに更新しているため、ライトモードも含めるのが合理的です。エージェントに追加で依頼し、ハイコントラストに加えてライトモードも実装してもらいます。

## Copilot cloud agent のタスクを確認する

Copilot cloud agent に割り当てたすべてのタスクの現在の状態を確認します。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方に表示されるタスク一覧を確認します。割り当てたタスクとして、次のような項目が表示されます。
   - コードベースのドキュメント更新。
   - ゲーム変更用 API の生成。
   - ウェブサイトへのハイコントラストモードの追加。
3. 実行中のタスクを選択し、Copilot が行った操作を確認します。次のような操作が含まれる場合があります。
   - リポジトリからコードをチェックアウトする。
   - Copilot が作業する環境を作成する。
   - MCP サーバーをセットアップする。
   - タスクを完了するためにさまざまな手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここでは、PR と変更されたファイルを確認し、追加で監視できます。

## cloud agent に追加の指示を出す

実行中のタスクを確認できたので、ハイコントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼します。

1. ハイコントラストモードの追加を示すセッションを選択します。正確なタイトルは Copilot が付けた名前や作業状況によって異なります。

   ![mission control のアクセシビリティ (Accessibility) セッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業を開始したことが示されるまで数分間セッションを確認します。次のようなメッセージが表示されたら、作業が始まっています。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

   ```plaintext
   ハイコントラストモードの作業に加えて、ライトモードも追加してください。このモードにも切り替え機能を用意し、利用者が表示モードを選べるようにしてください。
   ```

   ![エージェントページの cloud agent タスク。作業中のセッションに指示するダイアログが強調表示されている](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot が依頼を認識し、作業に取り入れることを確認します。

## Copilot に作業を任せる

これまでと同様に、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で作業していたステップが終わった後に、新しい依頼を作業の流れに取り入れます。

今回も数分かかります。その間、これまでに学んだことを振り返りましょう。

## まとめと次のステップ

GitHub Copilot cloud agent のタスクを監視して導くための中心的な場所である Copilot エージェントページを確認しました。この mission control では、進行中と完了済みのタスクを追跡し、実行中の作業をレビューし、進行中のタスクに追加の指示を出して範囲を調整できます。

次のことを確認しました。

- mission control とエージェントページで cloud agent のタスクを監視しました。
- 進行中のセッションに追加の機能を依頼しました。

Copilot がアクセシビリティ機能を実装している間に、次は[Copilot が作成したプルリクエストを反復的に改善します][next-lesson]。
